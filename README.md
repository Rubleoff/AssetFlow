# AssetFlow

AssetFlow — это полнофункциональное приложение для управления личными финансами с backend на FastAPI, frontend на React/Vite, фоновыми задачами и локальной Docker-средой. Система объединяет ежедневный учёт денежных потоков с активами, вкладами, целями, регулярными платежами, импортом данных, уведомлениями и аналитическими дашбордами.

## Возможности

- Счета и балансы
- Транзакции, переводы, категории и теги
- Бюджеты и уведомления о достижении лимитов
- Активы с ручной оценкой или рыночным отслеживанием цены
- Вклады и регулярные транзакции
- Финансовые цели и планирование пополнений
- Отчёты по сводке, денежному потоку, динамике категорий, мерчантам, аллокации и капиталу
- Сценарное моделирование
- Предпросмотр и применение CSV-импорта
- Ежедневные дайджесты и уведомления об аномалиях
- Административные инструменты для outbox-событий и фоновых задач Celery

## Структура репозитория

```text
.
├── api/                  FastAPI-приложение, SQLAlchemy-модели, Celery-задачи, тесты
├── web/                  React 19 + Vite frontend
├── infra/nginx/          Конфигурация локального reverse proxy
├── scripts/              Экспорт OpenAPI и генерация frontend-клиента
├── docker-compose.yml    Полный локальный стек
└── .env                  Локальные переменные окружения
```

## Архитектура

### Backend

Backend находится в `api/app` и организован вокруг следующих частей:

- `app/main.py`: настройка FastAPI-приложения, CORS, health endpoint, runtime-совместимость схемы БД
- `app/api/routes/*`: REST-эндпоинты для auth, users, accounts, transactions, planning, assets, reports, imports, notifications и admin-инструментов
- `app/models/*`: SQLAlchemy-модели для учёта операций, планирования, портфеля, импорта, уведомлений и снапшотов
- `app/services/*`: доменная логика для аналитики, учёта операций, импорта, сценариев, авторизации, сидирования демо-данных и рыночных данных
- `app/tasks/*`: Celery-приложение и фоновые задачи для регулярных операций, обновления снапшотов и обработки outbox-событий

API использует cookie-based аутентификацию с access и refresh токенами. Backend может автоматически создавать демо-данные при первом запуске и отдаёт OpenAPI-схему для генерации типов на frontend.

### Frontend

Frontend находится в `web/src` и использует:

- TanStack Router для маршрутизации
- TanStack Query для работы с серверным состоянием и инвалидацией кэша
- React Hook Form + Zod для форм и валидации
- Recharts для дашбордов и отчётов
- Сгенерированные OpenAPI-типы в `web/src/lib/generated`

Основные части frontend:

- `app/`: роутер, shell, логика темизации
- `routes/`: страницы приложения
- `components/`: общие UI-компоненты, drawer’ы и overlay
- `lib/`: API-клиент, query-хуки, форматтеры, каталог, уведомления, сгенерированные типы
- `styles/global.css`: дизайн-токены и глобальные стили интерфейса

## Основные сценарии работы

1. Пользователь регистрируется или входит через cookie-based auth.
2. Backend при необходимости создаёт демо-счета, транзакции, бюджеты, активы, цели и уведомления.
3. Пользователь управляет счетами, операциями, бюджетами, активами, вкладами, регулярными платежами и целями.
4. Изменения создают outbox-события.
5. Celery-воркеры обрабатывают события, обновляют аналитические снапшоты и создают дайджесты/уведомления об аномалиях.
6. Frontend использует аналитические эндпоинты для отображения дашбордов, трендов и сценарных прогнозов.

## Руководство пользователя

AssetFlow помогает вести личные финансы в одном месте: деньги на счетах, расходы, доходы, активы, вклады, цели, регулярные платежи, импорт и аналитику.

### Общие элементы

- `Добавить` в верхней панели создаёт объект для текущей вкладки: счёт, операцию, бюджет, актив, вклад, цель или регулярный платёж.
- Колокольчик открывает последние уведомления. Цифра на кнопке показывает непрочитанные события.
- Переключатель темы включает светлый или тёмный режим. Выбор сохраняется в браузере.
- Кнопка профиля открывает настройки пользователя и выход из аккаунта.
- `Изменить` открывает форму редактирования выбранного объекта.
- `Удалить` или `Убрать` удаляет объект либо выполняет выбранное действие после подтверждения.
- `+` в полях выбора открывает список вариантов: счёт, валюта, тип, статус или другой справочник.
- Сегменты и быстрые кнопки-пилюли выбирают тип операции, валюту, период графика или режим формы.

### Цвета графиков

- Зелёный: динамика положительная.
- Красный: динамика отрицательная.
- Жёлтый: динамика почти не изменилась или данных пока мало.
- Линия показывает сам ряд значений, заливка под ней помогает быстрее увидеть направление. Если линия идёт вверх, показатель растёт; если вниз, снижается.

### `Сводка`

Главный экран для быстрой проверки состояния финансов.

- `Доступно сейчас`: деньги, которыми можно пользоваться сразу.
- `Чистый капитал`: стоимость активов минус обязательства. Это то же, что `net worth`.
- `Расходы за месяц`: сколько уже потрачено в текущем месяце.
- `Остаётся от дохода`: процент дохода, который не ушёл в расходы.
- `Движение денег`: график доходов и расходов за последние дни. Помогает увидеть, когда расходы начинают обгонять поступления.
- `Как менялся чистый капитал`: график общей стоимости финансовой картины.
- `Что стоит заметить`: автоматические подсказки по рискам, расходам и запасу денег.
- `Главные статьи расходов`: категории, которые сильнее всего влияют на бюджет.

### `Счета`

Здесь хранятся банковские карты, наличные, брокерские и другие денежные счета.

- Карточки показывают название, тип, валюту, баланс и роль счёта в расчётах.
- `Добавить` создаёт новый счёт.
- `Изменить` меняет название, валюту, тип и параметры участия в капитале.
- `Удалить` убирает счёт, если он больше не нужен.
- Параметр `Учитывать в капитале` включает счёт в расчёт чистого капитала.
- Параметр `Учитывать в доступных деньгах` включает счёт в показатель ликвидного баланса.

### `Операции`

Раздел для ежедневного учёта доходов, расходов и переводов.

- Таблица показывает дату, счёт, сумму, категорию, мерчанта и описание.
- `Добавить` создаёт доход, расход или перевод.
- `Изменить` корректирует сумму, дату, категорию, счёт или описание.
- `Удалить` убирает ошибочную операцию.
- Доход увеличивает баланс, расход уменьшает, перевод переносит деньги между счетами.

### `Бюджет`

Раздел показывает, насколько текущие траты близки к лимитам.

- `Всего лимитов`: сумма всех запланированных лимитов.
- `Уже потрачено`: фактические расходы по бюджетам.
- `Прогноз`: ожидаемые расходы к концу периода при текущем темпе.
- Столбчатый график сравнивает лимит, факт и прогноз. Зелёный означает запас, жёлтый — близко к лимиту, красный — лимит превышен или почти превышен.
- Таблица показывает остаток, период и значения по каждой зоне бюджета.
- `Добавить` создаёт новый лимит.

### `Активы`

Раздел для инвестиций, недвижимости, криптоактивов, металлов и других позиций.

- Карточки показывают количество, текущую цену, стоимость позиции и прибыль/убыток.
- `Добавить` создаёт актив.
- `Изменить` обновляет параметры актива, количество, цену и настройки отслеживания.
- `Удалить` убирает актив из портфеля.
- Кнопки периода меняют диапазон графика цены.
- График цены показывает историю стоимости выбранного актива в базовой валюте.
- `Источник` показывает, откуда берётся цена: вручную, CoinGecko или Twelve Data.

### `Вклады`

Раздел для депозитов и накопительных продуктов.

- Карточки показывают банк, текущий баланс, ставку, дату открытия, дату окончания и ближайшую выплату.
- `Добавить` создаёт вклад.
- `Изменить` меняет ставку, баланс, даты, капитализацию и счёт пополнения.
- `Удалить` убирает вклад.
- `Капитализация` означает, что начисленные проценты прибавляются к сумме вклада и дальше тоже приносят проценты.

### `Цели`

Раздел для накоплений: подушка безопасности, крупные покупки, отпуск, ремонт.

- Прогресс-бар показывает, какая часть цели уже накоплена.
- `Осталось`: сколько ещё нужно накопить.
- `Комфортный взнос`: сколько стоит откладывать каждый месяц, чтобы прийти к цели.
- `Оценка срока`: примерное число месяцев до достижения цели.
- `Пополнить цель` переводит деньги со счёта в цель.
- `Забрать из цели` возвращает деньги из цели на выбранный счёт.
- `Изменить` открывает название, сумму цели, дедлайн, приоритет, статус и связанный счёт.
- Статус `В работе` означает, что цель участвует в прогнозах. `На паузе` временно выключает активное движение. `Готово` фиксирует достигнутую цель. `В архиве` скрывает цель из текущей работы.

### `Регулярные`

Раздел для повторяющихся доходов и расходов.

- Карточки показывают сумму, счёт, периодичность и ближайшую дату выполнения.
- `Добавить` создаёт зарплату, подписку, аренду, кредитный платёж или другой повтор.
- `Изменить` меняет сумму, расписание, счёт и категорию.
- `Удалить` отключает ненужное правило.
- Регулярные операции помогают строить прогнозы и заранее видеть будущие списания.

### `Отчёты`

Раздел для подробного анализа и импорта.

- `Динамика категорий` показывает, какие статьи расходов растут или снижаются.
- `Мерчанты` показывает магазины и сервисы, где чаще всего были траты.
- `Cash flow` — это денежный поток: доходы минус расходы по дням.
- График `Ежедневная серия движения денег` показывает чистый поток за каждый день.
- `Структура активов` показывает доли активов в общей стоимости.
- `Net worth` — чистый капитал: активы минус обязательства.
- `Предпросмотр импорта` проверяет CSV-строки перед записью. CSV — это таблица в текстовом формате, где значения разделены запятыми или другим символом.
- `Применить строки` записывает подготовленные операции в журнал.
- `Импортировать даже дубли` разрешает записать строки, похожие на уже существующие операции.
- `Экспорт CSV` выгружает операции в файл для таблиц или внешней обработки.

### `Сценарии`

Раздел отвечает на вопрос «что будет, если условия изменятся».

- Поля сценария меняют доход, гибкие расходы, регулярные платежи, взносы и рост активов.
- `Построить прогноз` рассчитывает будущие месяцы.
- График результата сравнивает баланс и чистый капитал по месяцам.
- `Месяцы дефицита` показывает, сколько месяцев баланс будет уходить ниже комфортного уровня.
- `Рост активов, %` — ожидаемый месячный рост стоимости активов.

### `Настройки`

Раздел для личных параметров приложения.

- `Базовая валюта` задаёт валюту, в которой считаются сводка и общий капитал.
- `Часовой пояс` влияет на даты операций, уведомлений и регулярных платежей.
- `Ежедневный дайджест` включает краткую ежедневную сводку.
- `Сигналы аномалий` включает предупреждения о необычных расходах.
- `CSV-разделитель` задаёт символ, которым разделены колонки в импортируемом файле.
- `Тип импорта по умолчанию` подставляет тип операции для банковских списаний.
- `Правило активно` включает или выключает правило обработки мерчанта.

### `Админ`

Служебный раздел для администратора.

- Показывает фоновые задачи, события outbox и технические статусы.
- Помогает проверить, что уведомления, снапшоты и регулярные обработки выполняются.
- Обычному пользователю этот раздел не нужен для ежедневной работы.

### Быстрый рабочий сценарий

1. Создайте счета и укажите стартовые балансы.
2. Добавьте операции вручную или загрузите их через CSV-импорт.
3. Настройте бюджеты и регулярные платежи.
4. Добавьте активы, вклады и цели.
5. Проверяйте `Сводку` и уведомления.
6. Открывайте `Отчёты`, когда нужно понять причину изменений.
7. Используйте `Сценарии`, чтобы оценить крупную покупку, рост расходов или изменение дохода.

## Локальный запуск

### Вариант 1: Docker Compose

Это самый простой способ запустить весь стек.

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу `http://localhost:8080`.

Compose поднимает:

- `nginx`
- `web`
- `api`
- `worker`
- `beat`
- `postgres`
- `redis`

### Вариант 2: запуск backend и frontend отдельно

#### Backend

Требования:

- Python 3.9+
- Удобно использовать `uv`, но подойдёт и `venv` + `pip`

Пример настройки:

```bash
cd api
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

По умолчанию backend может работать через SQLite (`sqlite:///./assetflow.db`), если переменные окружения не переопределены.

#### Frontend

Требования:

- Рекомендуется Node.js 22

Пример настройки:

```bash
cd web
npm install
VITE_API_BASE=http://localhost:8000/api npm run dev
```

## Переменные окружения

Основные backend-переменные:

- `APP_NAME`
- `API_PREFIX`
- `DATABASE_URL`
- `REDIS_URL`
- `SECRET_KEY`
- `CORS_ORIGINS`
- `CREATE_TABLES_ON_STARTUP`
- `DEFAULT_BASE_CURRENCY`
- `DEFAULT_TIMEZONE`
- `TWELVEDATA_API_KEY`
- `COINGECKO_API_KEY`

В `docker-compose.yml` уже заданы разумные локальные значения для большинства из них.

## Генерация API-типов

Frontend-типы генерируются из OpenAPI-схемы backend:

```bash
./scripts/generate_client.sh
```

Скрипт делает следующее:

1. Экспортирует OpenAPI JSON из FastAPI-приложения в `web/src/lib/generated/openapi.json`
2. Перегенерирует TypeScript-описания в `web/src/lib/generated/api-types.d.ts`

Запускайте его после изменения backend-схем или контрактов API.

## Тесты

### Backend

```bash
cd api
pytest
```

Сейчас тесты покрывают smoke-сценарии API, расчёты и поведение уведомлений/outbox-механизма.

### Frontend

```bash
cd web
npm test
```

Проверка типов и сборка:

```bash
cd web
npm run build
```

## Важные детали реализации

- Для поиска и оценки криптоактивов используется CoinGecko, для части рыночных инструментов — Twelve Data.
- Фоновые задачи обновляют снапшоты и генерируют дайджесты/уведомления об аномалиях.
- Пользовательские настройки включают параметры уведомлений и импорта.
- OpenAPI встроен в workflow проекта, поэтому frontend-типы синхронизированы с backend-контрактами.
- Интерфейс поддерживает светлую и тёмную темы.
